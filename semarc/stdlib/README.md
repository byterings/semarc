# SEMARC Standard Library Foundation

This directory is reserved for future semantic packages.

Packages must remain outside the core language. Future domains such as payment,
reporting, search, notifications, caching, storage, and auditing should be
modeled as packages or profiles instead of new core keywords.

Current status: `module.yaml` files are discovered and resolved for `USE` with their
dependencies, requirements and conflicts. Modules do not generate code yet.
